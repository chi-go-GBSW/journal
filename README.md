## 작성 규칙

1. 본인 폴더 안의 `week{N}` 폴더에 해당 주차 일지를 작성합니다.
2. 각 week 폴더의 `README.md` 템플릿을 채워서 사용합니다.
3. 하루치 일지가 필요하면 `week{N}` 폴더 안에 `YYYY-MM-DD.md` 파일을 추가로 만들어도 됩니다.
4. 주차가 부족하면 본인 폴더에 `week{N+1}` 폴더를 새로 만들어 이어서 작성합니다.

## 일지 템플릿

각 week 폴더의 `README.md`는 아래 항목으로 구성됩니다.

- 날짜
- 한 일
- 느낀점
- 다음주까지 계획
