# week2 일지

## 팀 정보
팀명: Hole in One
이름: 이동현

## 날짜
2026.9.2.

## 한 일
회의를 통해서 파크 골프에 대한 기본 지식에 대하여 배웠고, 백엔드 엔티티에 들어갈 인스턴스들을 구상하였다.
사용할 스택이 Fast API, MySQL을 베이스로 두고 개발을 진행한다는 계획을 세웠다.

## 느낀점
대회가 끝나고 중간에 왔기 때문에 스택은 무엇을 쓰고 어떻게 진행되는지 몰랐기 때문에 중간에 진입한다는 느낌이 좀 미안했고 힘들 것 같다는 생각이 들었다.

백엔드 개발 자체를 잘 못했기 때문에 프로젝트에 바로 투입되어 개발을 진행하는 것이 부담이 되긴 하지만 송민이가 잘 도와주는 덕분에 개발을 잘 할 수 있었다.

덕분에 나도 백엔드 개발을 열심히 공부해야겠다는 생각이 들었다.

## 다음주까지 계획
데이터베이스 명세서를 뽑아야 한다.
인스턴스를 상의해서 다다음주 대표님과 한 번 더 회의를 해봐야 할 것 같다.
Fast API 공부를 하여 기본 구동 원리를 공부할 것이다.
