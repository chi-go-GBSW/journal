# 7주차 프로젝트 일지

## 날짜

2026년 11월 4일

## 한 일

- 모바일 구장 선택 화면에서 백엔드 구장 목록 API(`GET /api/v1/venues`)를 호출하도록 연결했다.
- 구장을 펼치면 구장별 코스 API(`GET /api/v1/venues/{venue_id}/courses`)를 호출해 코스를 표시하고 선택하도록 구현했다.
- 검색, 로딩 표시, 코스 조회 오류 및 재시도, 선택한 코스 ID를 다음 화면으로 전달하는 흐름을 추가했다.
- 변경사항을 PR #70으로 병합했다.
- 구장 목록 API를 확인해 응답은 정상(HTTP 200)이지만 `total: 0`인 것을 확인했다. 개발 DB에 구장 데이터가 아직 등록되지 않아 실제 구장 목록 표시는 데이터 등록 이후 확인해야 한다.

## 느낀점

API 요청이 정상적으로 연결되어도 데이터베이스에 기준 데이터가 없으면 화면에 목록이 나타나지 않는다는 점을 확인했다. 화면 구현뿐 아니라 백엔드 데이터 준비와 실제 기기에서의 확인까지 이어져야 기능이 완성된다는 것을 배웠다.

## 다음주까지 계획

- 백엔드 담당자와 구장·코스 기준 데이터를 개발 DB에 등록한다.
- 데이터 등록 후 모바일에서 구장 검색과 코스 선택이 정상적으로 표시되는지 확인한다.
- 선택한 구장과 코스로 경기 생성 및 시작 API를 연결하고, 응답의 코스·홀 정보를 플레이 화면에 표시한다.
