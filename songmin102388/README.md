## 2026-10-21

## 한 일

FastAPI와 PostgreSQL 기반을 준비하고, 마일스톤 1 작업과 전체 백엔드 계획을 GitHub 브랜치에 정리했다.

마일스톤 2의 기능과 담당 범위를 나눴다. 동현은 Google 로그인·내 정보, 나는 구장·코스·홀 조회 API를 맡기로 했다.

동현에게 전달할 작업 안내서와 내 작업 안내서를 각각 Markdown 문서로 작성했다.

팀이 함께 쓸 DB 운영 방법을 검토하고, 외부 서버의 Docker PostgreSQL에 사설 VPN으로 접속하는 방식을 정리했다.

## 힘든 점

내 컴퓨터의 Docker DB를 동현과 공유하려면 외부 서버와 네트워크 설정이 추가로 필요해 구성을 이해하는 데 시간이 걸렸다.

DB 포트를 인터넷에 공개하지 않으면서 함께 접속하고, 마이그레이션 충돌도 막을 방법을 정해야 했다.

구장 원본 데이터에는 PAR·거리 확인이 필요한 값이 있어, API 개발용 데이터와 확정 데이터를 구분해야 한다.

## 잘한 점 / 아쉬웠던 점

마일스톤 2의 역할과 구현 순서를 나눠 각자 맡을 일을 문서로 남겼다.

데이터의 출처와 정확도를 확인한 뒤 사용하기로 해, 미확인 값을 확정 정보처럼 다루지 않도록 했다.

아직 마일스톤 2의 API 코딩은 시작하지 못했고, 공용 DB 서버도 실제로 구성하지 못했다.

## 다음 주까지 해올 것

팀 공용 DB를 둘 외부 서버를 정하고, Docker PostgreSQL과 사설 VPN 접속을 구성한다.

구장 목록·검색 API부터 구현하고, 구장 상세·코스 목록·홀 목록 조회로 확장한다.

동현은 Google 로그인과 내 정보 조회·수정 기능을 진행한다.

각 기능의 테스트와 API 문서를 확인하고, 마이그레이션 적용 순서를 팀과 합의한다.
