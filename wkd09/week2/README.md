## 일주일 동안 내가 만들어 낸 것

이번 주에는 캡스톤 프로젝트의 전체적인 방향과 진행 계획을 세웠다. 프로젝트에 활용할 데이터셋의 종류와 구성 방식을 조사했으며, STT(Speech-to-Text)의 기본 개념과 학습 방법을 공부했다. 이를 통해 앞으로 필요한 데이터와 기술을 정리하고 개발을 시작하기 위한 기초를 마련했다.

## 일주일 동안 겪었던 힘든 점, 극복했다면 해결 방법

STT 기술을 처음 접하다 보니 관련 용어와 전체적인 동작 방식을 이해하는 데 어려움이 있었다. 아직 잘 모르는 부분이 많지만, 기초 자료와 예제를 찾아보며 개념을 하나씩 정리하고 있다. 앞으로 직접 간단한 예제를 구현하면서 부족한 부분을 보완할 예정이다.

## 내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

프로젝트를 바로 개발하기에 앞서 계획을 세우고 필요한 데이터셋과 기술을 먼저 조사한 점은 잘했다고 생각한다. 다만 조사한 내용을 체계적으로 정리하고 실제 STT 예제까지 실행해 보지 못한 점은 아쉽다. 다음 주에는 학습한 내용을 기록으로 남기고 간단한 기능부터 직접 구현해 볼 계획이다.

## 다음 주까지 해올 것

- STT의 기본 원리와 활용 방법을 추가로 공부하기
- 수집한 데이터셋을 확인하고 학습에 사용할 수 있도록 정리하기
- 프로젝트의 초기 개발 환경을 구성하고 기본 기능 구현 시작하기
