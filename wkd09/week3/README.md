## 일주일 동안 내가 만들어 낸 것

이번 주에는 여러 STT 모델을 조사하고 직접 실험하여 성능을 비교했다. 비교 결과를 바탕으로 프로젝트에 사용할 베이스 모델을 선정했으며, OCR 벤치마크도 함께 확인하여 한국어 처리 성능이 뛰어난 모델을 선정했다. 단순히 모델을 선택하는 데 그치지 않고 성능과 활용 가능성을 비교하여 선정 근거를 구체적으로 정리했다.

## 일주일 동안 겪었던 힘든 점, 극복했다면 해결 방법

이번 주 회의를 진행하면서 실제 사용 환경에서 발생할 수 있는 여러 문제를 발견했다. 특히 시니어 사용자가 필드에서 서비스를 이용하려면 네트워크와 모바일 데이터가 필요하지만, 데이터 사용이 어렵거나 충분하지 않은 사용자도 있을 수 있다는 점이 문제였다. 아직 해결 방안을 확정하지는 못했으며, 로컬 모델 적용이나 데이터 사용량을 줄이는 방식 등 네트워크 의존도를 낮출 수 있는 방법을 추가로 검토할 예정이다.

## 내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

여러 모델을 직접 비교하고 베이스 모델의 선정 근거를 구체적으로 설계한 점은 잘했다고 생각한다. 반면 팀과의 소통이 부족했던 점은 아쉬웠다. 나는 로컬 모델을 사용하는 것으로 이해하고 있었지만 회의 중 API 사용 여부에 관한 질문을 받으면서 팀원들과 구현 방식에 대한 합의가 충분하지 않았다는 것을 알게 되었다. 앞으로는 중요한 기술적 결정을 미리 공유하고 적극적으로 의견을 주고받아 이러한 혼선을 줄여야겠다.
