## 일주일 동안 내가 만들어 낸 것

STT 음성 전처리를 적용한 뒤 한국어 음성 인식률이 낮아지는 문제를 확인하고, 원인을 찾기 위한 분석을 진행했다. 고정 seed(`20260930`)로 선정한 FLEURS 한국어 test 음성 100개를 비교한 결과, 전처리를 끈 조건에서는 전처리 실패가 없고 CER 5.56%, WER 15.58%였지만, 전처리를 모두 켠 조건에서는 42개 음성이 처리에 실패하고 CER 50.35%, WER 55.80%로 성능이 크게 떨어졌다.

실패한 42개는 모두 VAD가 최소 음성 길이 0.18초를 검출하지 못한 사례였고, 입력 음량이 -50.76 dBFS 이하인 반면 현재 VAD 임계값은 -42 dBFS인 것을 확인했다. 또 VAD를 통과한 58개만 따로 비교해도 원본보다 전처리 후 CER과 WER가 높았다. 특히 denoise를 끈 상태에서도 성능 하락이 나타나, denoise뿐 아니라 VAD 구간 자르기와 정규화의 영향도 분리해서 확인해야 한다는 점을 정리했다.

## 일주일 동안 겪었던 힘든 점, 극복했다면 해결 방법

사람의 음성을 더 정확히 알아듣게 하려면 어떤 전처리와 인식 방식을 적용해야 하는지 판단하는 일이 어려웠다. 전처리는 인식률을 높여줄 것이라고 기대했지만, 실제 평가에서는 낮은 음량의 발화가 누락되고 전처리를 통과한 발화의 정확도도 낮아졌다. 전체 전처리를 한 번에 비교하는 것만으로는 원인을 알기 어려워, 실패율과 CER·WER를 확인하고 VAD 미검출과 전처리 통과 후의 성능 저하를 별개의 문제로 나누어 분석하기 시작했다. 아직 해결책을 확정하거나 수정 후 재평가를 완료하지는 않았다.

## 내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

고정된 100개 표본과 동일한 평가 조건을 사용해 문제를 수치로 확인하고, 실패한 42건의 VAD 미검출과 통과한 58건의 인식률 하락을 구분해 살펴본 점은 잘했다고 생각한다. 또한 denoise만이 성능 저하의 원인이라고 단정하지 않고, 자르기와 정규화의 영향을 추가로 확인해야 한다고 판단했다. 아쉬운 점은 아직 발화별 전처리 결과와 시작·끝 음절이 잘리는지까지 분석하지 못했고, 수정 사항을 적용한 뒤 같은 표본으로 재평가하지 못한 점이다.

## 다음 주까지 해올 것

- 동일한 음성에서 원본, VAD 자르기만 적용, 자르기와 정규화 적용, 전체 전처리 적용 결과를 비교하기
- 낮은 음량의 실제 발화를 VAD가 놓치는 원인을 확인하고 음성 미검출 문제 수정하기
- 전처리 과정에서 발화 시작과 끝 음절이 잘리는지 확인하고 필요한 구간 보정 적용하기
- 수정 후 같은 FLEURS 100개 표본에서 CER, WER, 전처리 실패율 재측정하기
- STT 후처리 방법을 조사하고 적용 가능성을 시험한 뒤, 골프 명령 및 현장 소음 음성으로 별도 성능 테스트 진행하기
