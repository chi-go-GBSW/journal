## 한 일

## 어려웠던 점

## 잘한 점과 아쉬웠던 점

디자인 시스템 구축과 버튼 컴포넌트 제작을 완료 해 이후에 진행할 화면 디자인을 위한 기본적인 작업을 끝내었다.
