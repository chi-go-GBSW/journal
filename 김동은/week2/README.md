## 한 일

만들어놓은 디자인 시스템에 맞추어 서비스의 화면 대부분을 디자인하고 프로토타이핑까지 피그마를 통해 진행하였다. 프론트엔드로 사용될 스택인 React Native에서 구현 가능하도록 UI/UX를 작업했다.

## 어려웠던 점

서비스의 타겟 사용자가 시니어층이라서 UI 설계에 더 많은 고민을 쏟고 있다. 모바일 앱 디자인은 해본 경험이 꽤 있기때문에 괜찮지만, 노인들을 위한 UI 디자인을 처음이라 과연 지금 하고 있는 디자인이 실제로 효과가 있을지 조금은 의문이다.

## 잘한 점과 아쉬웠던 점

라운딩 화면들의 프로토타입을 작업하는 것이 조금 복잡했지만 결과가 잘 나와서 좋았다.

## 다음주까지 계획

기본적인 디자인을 끝내고 프론트엔드 개발을 시작하고 싶다. 아직 깃허브 사용법이 익숙하지 않아서 공부를 할 것이다. 또 리엑트 네이티브는 처음 사용해보는 것이니 개발환경을 구축하고 공부할 것이다.
