## 한 일

산학협력업체에서 학교로 찾아와 현재까지 진행된 디자인을 리뷰하고 캡스톤에서 구현해야 할 기능들을 명확히 했다. 회의를 진행하면서 어떻게 디자인을 해야 할지 감이 잡혔다.

## 어려웠던 점

디자인의 방향은 잡았지만 결국에는 사용 대상이 시니어층이라 디자인이 어렵다. 생각나는 것은 많은데 어떻게 디자인해야 할지, 시니어층이 사용할 수 있을지 아직도 의문이고 힘들다.

## 잘한 점과 아쉬웠던 점

현재까지 이루어진 디자인이 긍정적인 피드백을 받았다. 또 회의에 적극적으로 참여하여 프로젝트 디자인의 방향성을 잡았다.
